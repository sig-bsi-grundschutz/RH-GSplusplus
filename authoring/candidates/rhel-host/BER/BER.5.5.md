# BER.5.5 — Deaktivierung einfacher Biometrie auf IT-Systemen

## Control Statement

Berechtigung für IT-Systeme SOLLTE die Authentifizierung nur anhand von Biometrie deaktivieren.

## Review

PAM/fprintd-Konfiguration kann rein biometrische Authentisierung als alleinigen Faktor deaktivieren. Typischerweise eher für Clients relevant als für RHEL Server
